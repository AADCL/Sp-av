# 起飞与任务执行分步控制

2026-09-15，按用户确认，将 C++ OFFBOARD 的起飞和任务执行分开。此前起飞完成会自动进入 GUIDING；当前 `state=1` 只接管、解锁和起飞，随后在实际位置悬停，等待新的 `state=2` 开始任务。`state=0` 暂停，`state=3` 仍使用 PX4 AUTO.LAND。

本次修改同时适用于 direct 和 ego 模式。起飞前已加载的单点或序列不会自动执行；HOLDING 中收到新目标只加载，GUIDING 中的单点替换继续实时生效。起飞期间提前发送的 `2` 不排队；任务为空时收到 `2` 仍等待，加载目标后需发送新的执行命令。参数仍按数值变化处理。

EGO 规划许可、任务编号和首点等待计时从显式执行开始。第二轮起飞也会重新锁定参考并等待 `2`。基础系统、建图、重定位、机体几何、外参和 PX4 降落参数没有修改。
