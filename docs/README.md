# 涵道四旋翼无人机文档

控制指令采用分步操作：`state=1` 只起飞并悬停，`state=2` 才开始／恢复任务，`state=3` 降落；悬停时收到新目标只加载，不自动执行。

当前工作空间保留基础通信、建图、保存地图、重定位、外部里程计和独立传感器模块，新增 C++ `ducted_offboard` 执行器。EGO 源码保留但运行冻结，任务状态机与执行器分线程运行，当前直接跟踪任务点，没有自动避障。旧 Python 自动飞行代码保持归档状态。

地图通过 `map_file` 选择；任务手册中的 `flight_test_01` 仅为默认示例，可替换为当前场地的地图。控制器既可使用建图期间的定位，也可使用已有地图重定位。任务高度相对于本轮起飞点；起飞不依赖 `h_agl`。降落交给 PX4 `AUTO.LAND`。

当前自动控制使用 direct 分步流程，EGO 运行已冻结。新架构与软件证据见 [分层控制验证](verification/2026-09-15-offboard-split.md)。
