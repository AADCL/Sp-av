四份手册基于远程 `/home/nrc/catkin_ws` 的实际代码和配置编写，更新日期见各手册。机体尺寸为前后0.60 m、左右0.70 m、总高0.20 m，原点位于中心。

当前自动任务使用 `finish:=land`，下降和落地锁定交给 PX4；自定义 `slow_land` 仍禁用。软件验证与实机运行范围见[2026-09-12 原生降落验证](verification/2026-09-12-px4-native-landing.md)。
